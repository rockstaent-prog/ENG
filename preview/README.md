# 開いて操作できるお試し版

携帯では [公開した携帯版](https://rockstaent-prog.github.io/ENG/) の「携帯に保存」からホーム画面に追加します。`komorebi-mobile.zip` はHTTPSで配信するための一式で、携帯への直接インストール用ZIPではありません。初回保存後のオフライン再起動、アバターの拡大、選んだ画像の位置・大きさの保存をブラウザで確認しています。公開成功とURLはユーザー画面で確認済みです。この環境からの公開サイト接続は引き続き制限されています。

1. [アプリのZIPをダウンロード](https://github.com/rockstaent-prog/ENG/raw/refs/heads/main/preview/komorebi.zip)します。
2. 保存したZIPを開き、中の **「アプリを開く.html」** をダブルクリックします。

パソコン向けです。GitHubへのログインを求められたら、このリポジトリを開けるアカウントでログインしてください。

「学習する」でレッスン、「会話する」でEmmaとのガイド会話を操作できます。「アバター設定」から名前や画像を変えられます。発音は「あいさつを聞く」や返事の「聞く」で再生します。画像・画面・ガイド会話はこの1ファイルに含まれています。

開くと大きなEmmaの会話画面が出ます。**「あいさつを聞く」** を押すと、口元・まばたき・頭の傾き・うなずき・肩の動きが連動します。「履歴を広く」で文字を読みやすくでき、読み上げが始まるとアバター中心の表示へ戻ります。

会話には女性の声を使います。端末に対応する女性の英語音声がないときは、画面でお知らせします。携帯の縦画面・横画面に合わせた表示と、文字入力中も入力欄が見える配置に対応しています。

アバターをタップすると拡大できます。選んだ画像は設定画面のスライダーで、上下・左右・顔の大きさを調整できます。

新しく選んだ写真は「写真全体を映す」が初期状態です。上半身まで切らずに表示し、元の写真自体を動かします。「顔を拡大する」を選ぶと位置・拡大率の調整に切り替わります。最初にチャットへ送られた元写真そのものへの初期画像の差し替えは、再添付待ちです。

カフェで支払いを選んだときに同じ質問へ戻る不具合と、保存データが壊れていると復習画面が開けなくなる不具合を修正しています。全6レッスン・30問の完了、次のレッスンの解放、記録保存まで画面操作で確認しています。

Node.jsのインストール、ターミナル操作、APIキー、公開設定は不要です。ブラウザにローカルファイルの学習記録保存が許可されていれば、同じファイルを開き直しても記録を引き継ぎます。マイク・音声の利用可否はブラウザによって異なり、文字入力でも会話できます。自由なAI会話は別途APIを設定する通常版の機能です。

iPhoneの「ファイル」アプリ内プレビューなどはJavaScriptを実行しない場合があります。スマートフォンで確実に操作するにはHTTPSで配信するGitHub Pages版が必要です。

改善してほしい点は「どの画面で、何をしたら、どうなったか」をチャットで伝えてください。

開発時の再生成: `npm run build:standalone`。このコマンドは配布用の `komorebi.html` と `komorebi.zip` を更新します。ZIPの生成にはPython 3を使います。ダウンロードしてアプリを使う人にはPythonは不要です。

検証について: このクラウド環境の管理ブラウザは `file://` を禁止しているため、ローカルファイルとして直接開く検証は実行できません。テストでは他のファイルもAPIも用意せず、このHTMLだけをHTTP配信し、画像表示・会話・レッスン完了・記録保存・再読み込みを実ブラウザで検証しています。管理ポリシーでHTMLファイルの実行が禁止されているPCでは、GitHub Pages版を使ってください。
